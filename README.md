# Digital Design for Edge AI

Self-directed SystemVerilog portfolio focused on building the digital design foundations needed for edge AI hardware (quantized compute engines, memory structures, and control logic).

## Goals
- Master synthesizable SystemVerilog for combinational and sequential logic
- Develop clean, well-verified RTL that can later support fixed-point arithmetic and MAC units
- Build toward edge-AI datapaths (INT8 / binary compute, register files, simple accelerators)

## Current Progress

### Combinational Logic
- Basic logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- Half Adder & Full Adder
- 2-to-1 and 4-to-1 Multiplexers
- 4-bit Ripple Carry Adder
- Hexadecimal to 7-Segment Decoder

### Sequential Logic (in progress)
- D Flip-Flop with asynchronous reset
- Registers, shift registers, counters, and basic register-file / small memory structures

## Next Steps
- Finish sequential building blocks (registers, counters, register files)
- Control logic & simple FSMs (sequence detectors, ready/valid handshaking)
- Fixed-point arithmetic and MAC units
- Parameterized compute arrays aimed at edge inference
